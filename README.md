# KÁRMÁN

**Build. Launch. Explore.** A spaceflight and aerospace-engineering simulator for macOS (Unity 6.6, URP, Metal).

Current state: **Phase 1, Earth-orbit vertical slice.** A NASA Gemini spacecraft in a real 280 × 320 km orbit, with
the Earth, Moon, Sun and all eight planets placed by analytical JPL/Meeus ephemerides at the real date and time.
See [ROADMAP.md](ROADMAP.md) for what exists and what is next.

## Requirements
- Unity **6000.6.9f1** (Unity 6.6) with Mac Standalone support
- macOS on Apple silicon (developed on an M3 Pro)
- Blender 5.2+ only for re-running the asset pipeline in `Tools/Blender`
- Git LFS (textures and models are LFS-tracked)

## Open and play
1. Open `~/Projects/karman` in Unity Hub (6000.6.9f1).
2. Open `Assets/Karman/Scenes/Flight.unity` and press Play.
   If the scene is missing, run **Karman ▸ Rebuild Flight Scene** (the scene is generated by `KarmanSetup.cs`).

## Build from the command line
```sh
/Applications/Unity/Hub/Editor/6000.6.9f1/Unity.app/Contents/MacOS/Unity -batchmode -quit \
  -projectPath ~/Projects/karman -executeMethod Karman.EditorTools.KarmanSetup.BuildMac -logFile build.log
open Builds/macOS/Karman.app
```

Command-line options for the player:
- `-karmanDate 2026-11-18T06:00:00Z` start at a fixed UTC time (default: now)
- `-karmanCapture <dir>` scripted screenshot + frame-time run, writes `report.json`, then quits

## Tests
```sh
/Applications/Unity/Hub/Editor/6000.6.9f1/Unity.app/Contents/MacOS/Unity -batchmode -projectPath ~/Projects/karman \
  -runTests -testPlatform EditMode -testResults results.xml
```

## Vehicle Assembly Building
Click a part in the catalogue, then click a green node (or a tank surface for strap-ons). X cycles radial symmetry,
R rotates, Shift-click repeats, right-click cancels. Select a part and press Delete to remove it and everything below.
⌘Z / ⌘⇧Z undo/redo, ⌘S save (`~/Library/Application Support/com.karman.spaceflight/Craft`). Right-drag orbit,
scroll zoom, middle-drag or Shift+scroll height, F frame. Staging: select a part, ▲/▼ to move its stage, Auto to reset.

## Launching
Build or load a craft in the VAB and press **LAUNCH**. It stands on LC-39A at Kennedy. Press Z (full throttle) and Space
to ignite, or **G** for the ascent assistant, which flies to a ~190 km orbit using the same controls you have.
Time warp , and . (up to 5× keeps full physics; higher warps are on rails and only allowed above the atmosphere).

## Planning maneuvers
Open the map (M). Click the blue trajectory to place a node, then use the planning panel to add prograde / normal / radial
Δv and shift its time (or use Node at Ap/Pe, Circularise, Plan Moon transfer). The orange line is the trajectory after the
burn; encounters and closest approaches are labelled. EXECUTE (or N in flight) warps to the burn and flies it.

## Going to the Moon
Main menu ▸ **Moon Mission from the Pad** puts the Kármán V with the lunar lander on LC-39A (G flies it to orbit; then
plan the Moon transfer on the map). The VAB's **Moon rocket** button loads the same vehicle for editing.

Main menu ▸ **Lunar Landing** starts in a 100 km lunar orbit: press **G** to deorbit and land on real LOLA terrain, then
**G** again to lift off back to orbit; open the map and press **Return to Earth** to plan the trans-Earth burn, EXECUTE it,
and arm the parachute with **C** before entry. **Lunar Mission** starts the full stack in a low Earth orbit in the Moon's
plane: map ▸ **Plan Moon transfer** ▸ EXECUTE, then circularise at the Moon and land.

## Image generation (optional)
`Tools/ImageMCP/server.py` is a local MCP server (`karman-images`, registered in `.mcp.json`) for OpenAI and Gemini image
models. Keys come from `OPENAI_API_KEY` / `GEMINI_API_KEY`. Generation is blocked unless `KARMAN_IMAGE_BUDGET_USD` is
set; every image is logged in `AI_ASSET_LOG.md`. Setup: `python3 -m venv Tools/ImageMCP/.venv &&
Tools/ImageMCP/.venv/bin/pip install mcp openai google-genai pillow`, then approve the server when Claude Code asks.
