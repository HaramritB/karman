# KÁRMÁN

**Build. Launch. Explore.** A spaceflight and aerospace-engineering simulator for macOS (Unity 6.6, URP, Metal).

Current state: **Phase 1, Earth-orbit vertical slice.** A NASA Gemini spacecraft in a real 280 × 320 km orbit, with
the Earth, Moon, Sun and all eight planets placed by analytical JPL/Meeus ephemerides at the real date and time.
See [ROADMAP.md](ROADMAP.md) for what exists and what is next.

## Requirements
- Unity **6000.6.9f1** (Unity 6.6) with Mac Standalone support
- macOS on Apple silicon (developed on an M3 Pro)
- Blender 5.2+ only for re-running the asset pipeline in `Tools/Blender`
- Git LFS (textures and models are LFS-tracked)

## Open and play
1. Open `~/Projects/karman` in Unity Hub (6000.6.9f1).
2. Open `Assets/Karman/Scenes/Flight.unity` and press Play.
   If the scene is missing, run **Karman ▸ Rebuild Flight Scene** (the scene is generated by `KarmanSetup.cs`).

## Build from the command line
```sh
/Applications/Unity/Hub/Editor/6000.6.9f1/Unity.app/Contents/MacOS/Unity -batchmode -quit \
  -projectPath ~/Projects/karman -executeMethod Karman.EditorTools.KarmanSetup.BuildMac -logFile build.log
open Builds/macOS/Karman.app
```

Command-line options for the player:
- `-karmanDate 2026-11-18T06:00:00Z` start at a fixed UTC time (default: now)
- `-karmanCapture <dir>` scripted screenshot + frame-time run, writes `report.json`, then quits

## Tests
```sh
/Applications/Unity/Hub/Editor/6000.6.9f1/Unity.app/Contents/MacOS/Unity -batchmode -projectPath ~/Projects/karman \
  -runTests -testPlatform EditMode -testResults results.xml
```

## Controls
| Action | Keys |
|---|---|
| Pitch / yaw / roll | W S / A D / Q E |
| Throttle up / down, full, cut | Shift / Ctrl, Z, X |
| SAS on/off; hold, prograde, retrograde, normal, anti-normal, radial out/in | T; 1 2 3 4 5 6 7 |
| Time warp down / up / real time; pause | , / . / `/`; P |
| Orbit camera, zoom | right-drag, scroll (or = / -) |
| Cycle focus (vessel, Earth, Moon, Sun), back to vessel | V, Backspace |
| Map view, next focus | M, Tab (click a label to focus) |
| Controls panel | F1 |
